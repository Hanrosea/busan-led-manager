# 부산시내버스 행선지안내기 통합관리프로그램 개선안

2026-11-12 요청사항을 반영한 독립 실행형 프런트엔드입니다. 기존 서버 소스/API가 제공되지 않아, 구성도와 요청사항을 기준으로 화면을 재구성했습니다.

## 최신 반영사항

2026-11-12 배포 버전 2: 단말기상태정보의 펌웨어 현재버전·미래버전·적용일시 입력칸 너비와 간격을 조정했습니다. 좁은 화면에서 상단 적용 항목이 줄바꿈되며, 표 안의 버전·일시 칸도 충분한 폭을 확보했습니다.

GitHub 업로드 및 테스트 서버 배포는 `DEPLOY.md`를 참고하세요.

## 실행

Node.js 18 이상이 설치된 PC에서 압축을 해제한 뒤 이 폴더에서 `node server.cjs`를 실행하고, 출력되는 주소로 접속합니다. 별도 npm 패키지 설치나 빌드 과정은 없습니다. Windows에서는 `start.bat`를 실행할 수 있습니다.

정적 웹서버에 배포할 때는 `dist` 폴더 내용을 서비스 루트에 올립니다. 메뉴 전환은 URL 해시를 사용합니다.

## 반영 내용

| 메뉴 | 내용 |

| 노선정보관리 | 운수사별 → 노선별 → 차량별 조회/적용. 현재버전, 미래버전, 미래버전 적용일시. 기존 행선지 및 경유지 관리 메뉴 제거. |

| 버스관리 / 버스정보 | 기존 차량정보 열 유지, 운수사·인가노선 조회 필터 제거. 행복사·행추가·열추가·삭제·엑셀 불러오기·버전선택·버전입력·저장. 엑셀 저장도 지원. |

## 사용 방법

1. 파일관리에서 펌웨어 또는 노선데이터를 등록하거나 메세지를 작성합니다.
2. 해당 조회/적용 메뉴에서 대상별 설정을 바꾸고 **적용**을 누릅니다.
3. **전체적용**은 현재 검색 결과에 포함된 대상 전체에 반영합니다. 확인창에서 대상 차량 수를 확인할 수 있습니다.
4. 버스정보는 목록을 편집하고 버전명을 입력한 뒤 저장합니다. 새 이름은 새 버전, 기존 이름은 해당 버전 수정으로 처리합니다.

운수사·노선·차량 조회는 동일한 차량별 설정을 공유합니다. 운수사 또는 노선에 적용하면 그 시점에 포함된 차량 설정을 갱신하며, 나중에 추가된 차량에 자동 상속되지는 않습니다. 개별 설정이 서로 다르면 상위 조회에 `혼합`으로 표시합니다. 마지막에 적용한 설정이 해당 차량에 반영됩니다.

미래버전 적용일시는 한국시간(UTC+09:00)으로 입력합니다. 예약 해제를 선택하면 미래버전과 일시를 비웁니다. 적용 중이거나 예약·장비 보고 버전에 연결된 파일은 참조가 남아 있으면 삭제할 수 없습니다.

## 파일 및 엑셀

- 버스정보: XLSX 첫 시트, CSV, TSV. 첫 행은 열 이름이며 운수사·인가노선·차량번호가 필수입니다. 중복 차량번호는 저장하지 않습니다.
- XLSX의 날짜 셀을 `YYYY-MM-DD`로 불러오며, 내보내기는 값 보존을 위해 텍스트 셀로 기록합니다. 서식·수식·매크로를 그대로 복제하는 기능은 아닙니다.
- 노선데이터: 파일 원본 등록. XLSX·CSV·TSV·JSON·TXT는 등록내용 미리보기, ZIP·BIN 등 다른 형식은 원본 보관 및 다운로드를 지원합니다.
- 메세지: 본문과 색상으로 JSON 생성. 기존 TXT 또는 `{ "text": "문구", "color": "#ffdf44" }` JSON을 불러올 수 있습니다.
- 이미지: 등록 이미지 미리보기. 미리보기 메뉴에는 이미지 또는 기타 파일을 등록할 수 있습니다. 실제 전광판 규격에 따른 렌더링 엔진은 포함하지 않습니다.

## 현재 구현 범위와 서버 연동

이 버전은 화면 검토용입니다. 예시 차량·노선·장비 데이터이며 실제 운영 데이터가 아닙니다. 파일 등록, 조회, 편집, 적용 설정, 게시글 저장은 브라우저에서 동작합니다.

- 설정: `localStorage`, 파일 원본·첨부: `IndexedDB`. PC·브라우저·사이트 주소별로 분리되며 공동 저장소가 아닙니다. 브라우저 데이터 삭제 시 사라집니다.
- 실제 장비 전송, 예약시간 자동 실행, 장비 수신정보 갱신, 계정 인증·권한 검증은 구현되어 있지 않습니다. 검토용 로그인은 인증 기능이 아닙니다.
- 파일 크기 상한은 50MB이며, 브라우저의 저장공간 제한이 우선합니다. 대형 노선표는 브라우저 설정 저장공간을 초과할 수 있습니다.
- 운영 서버에 연결할 때 `app.js`의 `persist`, `blobPut/Get/Delete`, 적용 함수와 게시판 저장 함수를 기존 API로 교체하고 서버에서 권한·파일·버전·예약을 검증해야 합니다.
- 서버는 차량·장비 식별자, 버전 ID, 대상 목록과 한국시간 예약일시를 받아 배포 작업을 생성하고 실제 보고값을 별도로 갱신해야 합니다. 버전 적용 설정만으로 실제 FW 버전을 변경하지 않습니다.

실제 서버 및 전광판과의 통합시험은 진행하지 않았습니다.
